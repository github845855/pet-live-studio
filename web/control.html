B 站直播间

只读接收弹幕、礼物、进场和关注

尚未连接设置房间号后开始只读连接
如何获取 B 站登录态（仅在需要时）
  1. 先在浏览器登录自己的 B 站账号并打开任意 bilibili.com 页面。
  2. 按 F12，在「应用程序 / Application」→「Cookie」→「https://www.bilibili.com」中找到 SESSDATA。
  3. 只复制 SESSDATA 对应的值，粘贴到上方并保存。不要分享或截图这个值；它相当于账号登录凭证。

登录态可用于需要登录权限的消息；普通弹幕中的昵称通常会由 B 站事件直接提供。SESSDATA 过期后请在 B 站重新登录并替换。

抖音直播间

通过本机 DyHub 桥接接收弹幕、礼物和进场

DYHUB
打开 DyHub ↗
尚未连接先启动 DyHub，再填房间号
最简单的抖音接入方式

推荐继续用 DyHub：它负责适配抖音变化，本项目只接收本机转发的标准弹幕，不需要在这里填抖音 Cookie，也不需要在浏览器控制台粘贴脚本。

  1. Windows 安装并启动 Docker Desktop。
  2. 在 PowerShell 执行下面两行，首次启动会下载并构建服务：
git clone https://github.com/ymstar/dyhub
cd dyhub
docker compose up -d --build
  1. 打开 DyHub 控制台，按它的页面提示添加并连接直播间。
  2. 回到这里填入直播间号，点击「连接 / 测试」。

DyHub 依赖抖音网页协议，平台更新时可能需要更新 DyHub；这是目前比在本项目里维护私有协议抓取更省事、也更容易维护的做法。

抖音没有公开稳定的网页弹幕接口；这里用 MIT 许可的 DyHub 做本机桥接，弹幕只在本机传递，不需要把 Cookie 交给 Pet Live Studio。

记住最近的话题，支持多轮对话和连续小故事

0条记忆

会记住最近几轮观众互动和宠物的自言自语，用于连续对话与连续剧情；保存在 runtime/memory.json，只在本机使用。关闭后模型既不读取也不写入记忆。小模型建议 4–6 条，条数越多提示词越长。
